렉쳐노트 `[렉쳐노트 Q&A]` 답변을 채울 때 **글을 길게 쓰지 말 것**. 비전문가 친화적 설명(비유, 풀어쓰기)은 가끔 넣는 건 좋지만, 매번 넣고 길어지면 오히려 가독성이 떨어진다.

**Why:** 2026-08-10 사용자 지적. 답변 하나에 콜아웃 3~4개 + 표 2개 + 소제목 3개를 넣었더니 "너무 길어서 가독성이 떨어진다"는 피드백을 받음. 렉노 Q&A는 그 자리에서 막힌 것을 뚫는 용도지 새 섹션을 쓰는 게 아님.

**How to apply:**
- 기본은 **핵심 답 → 근거/숫자 → 한 줄 정리** 정도. 콜아웃·표는 꼭 필요할 때 1개 수준.
- 비유는 이해에 결정적일 때만 하나.
- 터미널 응답도 같은 원칙 — 패널에 넣은 내용을 다시 길게 요약하지 말 것.
