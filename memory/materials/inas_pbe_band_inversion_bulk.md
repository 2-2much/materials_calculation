2026-08-18, `04-Facet_IP-EA/06-bulk_ref/PBE-d` 실측 (conventional 8원자, a0=6.189842,
ENCUT 400, PREC=Accurate, LASPH, ISYM=0, ISMEAR=0/SIGMA=0.05, Γ 8×8×8 → NKPTS 260).
기하는 완벽한 zincblende (In–As = 2.6803 Å = a0√3/4 정확).

★ **Γ1c 가 Γ15v 보다 0.55 eV 아래** = 갭이 닫힌 게 아니라 **역전**. InAs·InSb·HgTe 의
잘 알려진 PBE 실패다. [[bulk_vas_jt_isym_artifact]] 의 "PBE bulk InAs gap = 0.0000" 은
이 현상을 갭 0 으로 본 것.

## 여파 3가지

1. **점유도로 VBM 을 찾으면 안 된다.** `max(eig[occ>=0.99])` 는 전도대(3.6906, 엉뚱한 k)를
   집는다. 실제 VBM 인 Γ15v 는 오히려 **부분점유(0.741)** 라 "점유 상태" 필터에서 빠진다.
2. **슬랩이 두꺼워지면 금속화하는 게 정상.** 얇을 땐 양자구속으로 갭이 열려 있다가
   (예: (110) 6L 0.432 eV → 8L 0.266 eV → 10L 금속) 두꺼워지면 벌크 반금속성이 드러난다.
   계산 오류가 아니다.
3. **EA 를 PBE 로 내면 안 된다.** `EA = IP − E_g` 인데 PBE E_g 가 음수다.
   → 정렬항(V_vac − V̄_slab)만 PBE 에서 쓰고 **E_g 는 bulk HSE06** 에서 가져올 것.
   정렬항은 정전기량이라 범함수 의존이 거의 없다.

## VBM 특정 규칙 (04-tools/macroavg.py 에 구현)

**Γ점에서 '점유가 남아 있는 것 중 가장 높은 3중축퇴'** (SOC 없으면 Γ15v 는 정확히 3중축퇴).
⚠ 단순히 "가장 높은 3중축퇴" 는 틀린다 — Γ 에 3중축퇴가 8개 있고 위쪽 둘(5.4841, 5.8660)은
전도대다. 점유도 조건(mean occ > 0.1)이 있어야 3.8258 을 고른다.

**확정값: `V̄_bulk = 0.0000` (VASP 가 셀평균 정전기 전위를 0 으로 잡는다),
`ΔV_bulk ≡ E(Γ15v) − V̄_bulk = 3.8258 eV`.**

⚠ SOC 없음. 켜면 Γ15v 가 Γ8(VBM)+Γ7 로 갈리고 VBM 이 Δ_SO/3 ≈ +0.13 eV 올라간다.
세 facet 공통 벌크 항이라 **상대 정렬에는 안 들어오고** 실험 절대비교 때만 상수로 얹는다.
