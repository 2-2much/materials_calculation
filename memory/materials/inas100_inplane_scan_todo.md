## ⚠ 최대 발견: mono-alt 로는 p4×3 / p4×5 를 만들 수 없다

`make_100slab.py` L151-160 의 `cl_mode` 규칙상 **mono-alt 는 Cl 소속 In 이 `iy % 2`
함수** = **b축 주기 정확히 2** (p(2×2)). b 를 홀수배 하면 주기경계에 **antiphase
domain wall** 이 생겨 배치가 깨진다.
⚠⚠ **스크립트는 a축(dimer축) 홀수만 `raise` 하고 b축 홀수는 조용히 통과시킨다** —
경고를 기대하지 말 것. `verify()` 도 배위수만 보므로 못 잡는다.

| cl_mode | a 배수 | b 배수 | p4×3 | p4×4 | p4×5 |
|---|---|---|---|---|---|
| mono-alt p(2×2) | 짝수 | **짝수** | ✗ | ✓ | ✗ |
| **mono-A p(2×1)** | 짝수 | 제한 없음 | ✓ | ✓ | ✓ |

**결정 = mono-A 로 전환**(사용자 승인). 근거: ⑴ 비용이 **8.3 meV / 2×2 셀**(4.2 meV/Cl)
뿐이고 갭도 열린다, ⑵ **b축 주기가 1이라 표면 자체가 b\* zone-folding 을 안 만든다**
→ 결함 밴드의 b-분산을 깨끗하게 읽는 데 오히려 유리, ⑶ LDA 선례(acetate 전면 균일)와
같은 성격. 이완된 mono-A 2×2 의 b-주기-1 은 실측 **0.000018 Å** 로 엄밀 → 타일링 정당.

## 결함 정의 (확정)

표면 In-dimer 의 **맨(Cl 없는) In → As**, 그 위에 Cl 1개 추가(파트너 Cl 의 거울상).
Δn_Cl=+1. As_In 이 +2e, Cl 이 −1e → **NELECT 홀수 = 홑전자 1개** → **ISPIN=2 필수**.
LDA 선례의 "antibonding 에 전자가 차서 갭 안으로 내려온다" 와 정확히 일치.
As_In 은 아래 As 2 + dimer 파트너 In 1 + 새 Cl 1 = 4배위, Cl–Cl 최소 3.09 Å.

## ⚠ 검증 에이전트가 잡은 버그 (전부 수정) — 재발 방지용

1. **🔴 `expand_from_p4x3.py` 가 "최고 z 의 As" 로 결함 탐색.** 이완 후 As_In 이 표면 In
   면 **아래 0.573 Å** 로 내려가 0.5625 Å 창을 10 mÅ 차이로 이탈 → `found 0` 로 즉사,
   p4×4/p4×5 가 시작하자마자 죽을 뻔했다. **결함 식별은 항상 `find_defect`(Cl 결합 As)**.
   같은 휴리스틱이 `set_magmom.py`·`analyze_band.py` 에도 있었고 앞서 고쳤었는데
   **expand 만 빠뜨렸다** — 한 곳 고칠 때 전수 검색할 것.
2. **🔴 `finished()`="General timing" 은 미수렴을 통과시킨다.** VASP 는 NSW 소진·STOPCAR
   정지에도 이 문자열을 쓴다. 이완 단계는 반드시 `reached required accuracy` 로 볼 것.
3. 재개 시 **`ISTART=1` 승격은 WAVECAR 의 옛 스핀상태로 MAGMOM 을 무력화**한다
   ([[spin_stage_symmetry_never_broken]] 과 같은 함정) → 승격과 MAGMOM 주입은 배타.
4. `analyze_band` 의 "E_F 이하 최고 상태" 기준선은 **홀전자 결함에선 결함준위 자신** →
   host VBM(결함 무게 < 0.05)으로 잡을 것. 분산 폭은 차분이라 무영향.
5. setup 스크립트가 **실행 중 스테이지의 POSCAR 를 덮어쓰지 않도록** OUTCAR 가드.

## ⚠ 결함 밴드 식별은 **절대 무게로 하면 안 된다**

같은 상태의 투영 무게가 p4×3 **0.068** → p4×4 **0.046** 으로 희석된다(비편재 상태는
1/N 로 준다). 고정 문턱 0.05 를 쓰니 p4×4 결함 밴드가 **host 로 오분류**돼 보고 갭이
0.05 eV 로 붕괴했다. → **균일분배 대비 농축비**(n_ions/n_atoms)로 판정할 것:
실측 p4×3 **4.31×**, p4×4 **3.88×**, 이웃 host 밴드는 ≤2.9× → 문턱 2.5× 로 안정.
(`analyze_band.defect_mask`). 농축비가 4배뿐인 것 자체가 **거의 비편재**라는 증거다.
