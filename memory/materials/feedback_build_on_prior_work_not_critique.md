스토리·논문 문장에서 선행연구를 "틀렸다/답한다/정면 대립/반론" 구도로 짜지 말 것. "그들이 세운 것 위에 보완 경로를 더한다" 구도로.

**Why:** 2026-10-12 사용자: "우리는 발전시키려는 것이지 그분을 비판하는 게 아니다. 논문 초보인 나만 평판이 깎이고 더 크게 공격받을 수 있다." (내가 Schultz 대비 표를 '반박' 톤으로 짜자 나온 말.) 해당 분야 저자가 리뷰어가 될 가능성도 큼.

**How to apply:**
- 선행연구의 진단·검사법을 **우리 검증 프로토콜로 채택**("following Schultz et al., we check ...")해서 비판을 감사로 바꾼다.
- 결과가 다르면 "누가 맞나"가 아니라 **차이의 출처 후보(범함수·셀·SOC·k점)를 열린 질문으로** 제시하고 실험 판정에 맡긴다.
- 한계 지적은 상대 논문의 한계가 아니라 **"두 접근의 상보성"**으로 쓴다(예: ba-occ는 큰 셀·준위, 하이브리드는 CBM을 같은 계산 안에서).
