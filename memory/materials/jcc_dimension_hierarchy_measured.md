## ★ 왜 1D 에는 SEJM 이 없는가 (2026-09-23, 사용자 통찰)

2D 에서 `ΔH_f(3DJM) = ΔH_f0 + γ/L_S + q²L_z/(24ε_⊥L_S²)` 의 젤리움 항은

- **L_z 에 선형이고 절편이 구조적으로 0** → 0 이 되는 곳이 **기하학적 극한**(진공 소멸)
- 계수 K = πe²/6 에 **재료 길이가 안 들어간다** (`02-Lz_scan` −7.295 vs −7.540, −3.2%)
- 직선이라 두 점이면 되고 외삽이 안정 → `L_z→0` 이 곧 2DJM. 그래서 SEJM 이 **공짜 검증자**가 됐다 ([[jcc_fig2_sejm_reproduction]])

1D 는 `−ln L⊥` 이라 0 이 되는 곳이 극한이 아니라 **뿌리** `ln L⊥ = C` 다.

| | 실측 |
|---|---|
| δE₀ = 0 인 L⊥ | **11.19 Å** |
| 튜브 지름 2R | 4.25 Å (이웃 튜브 간격 6.93 Å) |
| L⊥⁰/R | 5.26 → ln = 1.66 |

선전하의 2D Madelung 이 `λ²[−ln(L⊥/R)+const]` 라 **C ≈ ln R + O(1)** — **보정식에 재료 길이(튜브 반지름)가 들어온다.** 2D 엔 없던 일이다.
기하로도 막혀 있다: 2D 모델 시트는 두께 0 이라 진공을 짜낼 수 있지만 **튜브는 유한 단면**이라 L⊥ → 2R 이 한계이고 거기선 이웃 튜브 밴드가 겹친다.

| 물질 | 진공 | 젤리움 항 | 0 이 되는 곳 | SEJM |
|---|---|---|---|---|
| 2D 시트 | L_z (1) | ∝ +L_z | L_z → 0 (기하 극한) | **있다** |
| 1D 튜브 | L⊥ (2) | ∝ −ln L⊥ | ln L⊥ = C (재료 의존) | **없다** |
| 0D 점 | L (3) | ∝ 1/L | L → ∞ | = 큰셀 외삽 |

## ⚠ 0D 는 더 나쁘다 — QD 계획의 핵심 제약

2D 는 (L_z, L_S), 1D 는 (L⊥, L_ax) 로 **젤리움 항과 이미지 항이 다른 축에 살아서** 분리해 잴 수 있었다.
**0D 엔 물질 방향이 없다.** 젤리움 Madelung 도 1/L, 결함–결함 이미지도 1/L — 같은 꼴이라
**어떤 셀 조작으로도 분리되지 않는다.** C60 로 갈 때 "δE₀ 가 무엇을 재는가" 를 **기하로 확인할 길이 원리적으로 막힌다**
→ 남는 것은 전자구조 항등식뿐이다 ([[jcc_dE0_koopmans_janak]]: δE₀(+1) = −I_H − ε_HOMO).

→ 결과의 다른 쪽 절반은 [[jcc_lax_axial_jcc_slower]]
