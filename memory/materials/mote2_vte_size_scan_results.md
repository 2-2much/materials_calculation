- 판정 기준 W<30 meV 는 **n5 부터 통과**

## ★★ V_Te 는 도너가 아니다 — 전자 2개가 Mo–Mo 결합에 먹힌다

전자 세기는 맞다: `650 → 644`, 중성 Te 가 6개만 가져가므로 **2개가 남는다**.
그런데 그 2개가 어디로 가는지는 세기가 아니라 준위 위치가 정한다. n5 실측:

```
밴드 322 (최고 점유)  E−VBM=0.000  3Mo무게 0.060 (0.5×)  = host 밴드
밴드 323/324          E−VBM=0.887/0.896  무게 0.507 (4.2×)  점유 0.000  ← 결함 e, 비어 있음
밴드 325 (host CBM)   E−VBM=1.262
```

- **점유 영역 전체에 국소 결함 상태가 없다**(전 밴드 훑음. 걸린 건 −60/−34 eV Mo semicore뿐)
- 대신 **Mo–Mo 가 3.5026 → 3.2095 Å (−8.4%)**, 이완에너지 **0.351 eV**, 이온 스텝 84
  (pristine 은 0.002 eV, 2스텝)
- → 남은 2개는 **빈자리를 가로지르는 Mo–Mo 결합에 화학적으로 소모**되고 그 준위는 VB 아래로 가라앉는다
- 이온성(MgO·ZnO 산소공공=F-center 도너)과 갈리는 지점. **MoTe2 는 공유결합적**
- 문헌 일치: MoS2 V_S 는 "**갭 안 깊은 준위 하나**, E_C−0.5 eV, STS 확인". 우리 PBE는 CBM−0.28 eV
- **자성 후보는 q=−1**(e¹ → 1 μB + **Jahn-Teller**). ⚠내가 처음 말한 "q=+1에서 자성"은 **오류**
  (최고 점유가 host 밴드라 정공이 비국소)

## ⚠ 갭 안에서 E_F 선은 점유를 뜻하지 않는다
Yelgel 논문 Fig.2b 는 결함 밴드가 E_F 에 붙어 보이지만, VBM 기준으로 맞추면 우리와 같다
(논문 결함준위 ≈VBM+0.8 / 우리 +0.89, CBM ≈+1.3 / +1.17). 갭이 스미어링보다 넓으면
E_F 위치는 코드가 임의로 찍는다. **점유는 EIGENVAL 점유수로만 판정할 것.**
논문 Table 1 의 "V_Te gap 0.711 eV"가 곧 VBM→빈 결함준위 간격이다(SOC·격자상수 차이로 우리 0.89와 다름).

## 스핀
MAGMOM 2 μB×3Mo(총 6, 물리 상한 2의 3배)로 세게 밀어도 `mag=0.0009` → **비자성 확정**.

## 도구 (03-Defect/tools/)
- `plot_band.py` + `plot_band.sh` — **bandos(~/bin/band) 는 여기서 못 쓴다**:
  KPOINTS 라벨을 `! G` 로 쓰면 VASP 가 주석 처리해 `<kpoints_labels>` 가 안 남고
  bandos 가 `UnboundLocalError` 로 죽는다(그쪽 버그). `make_kpath.py` 에서 `!` 제거함
- `sh plot_band.sh fat VTe` — MAGMOM_VTe 에서 이웃 Mo 번호를 자동으로 뽑아 fatband
- ★E_F 는 **반드시 02-relax_sp 균일 메쉬**에서. line-mode(ICHARG=11) E-fermi 는 신뢰 불가

## ⚠ 결함 셀은 밴드 선이 더 많아 보인다 (정상)

포개지고 Γ-M 선상에서 78개. 결함이 대칭을 깨면 83/123 으로 풀린다(배수 1.65→1.02).
