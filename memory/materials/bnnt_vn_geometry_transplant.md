`15-Lax_scan_BNNT` 의 `make_cells_VN.py`. **13/VN_p1/CONTCAR 은 9 단위(22.575 Å) 셀 하나**라
12·15·18 단위 셀을 만들려면 늘어난 부분을 채워야 한다. 그냥 무결함 단위를 붙이면 안 된다:

★ **이완 변위가 셀 경계(공공에서 11.3 Å)에서도 0.067 Å 로 살아 있다.** 정체 분해(2026-09-22):

| 후보 | 실측 | |
|---|---|---|
| 강체 평행이동 | ⟨u⟩ = 0 | 아님 |
| 균일 breathing | Δr(먼 원자) = +0.0001 Å | 아님 |
| 축 회전(제로모드) | θ 산포가 평균의 9 배 | 아님 |
| **무른 집단모드** | 단위 0↔8 이 0.013 Å 로 일치 · 그 자리 힘 0.004~0.006 eV/Å → **k ≈ 0.08 eV/Å²** | ★ 이것 |

에너지로 ~10 meV. EDIFFG = −0.01 문턱에 걸려 남은 것이고, 공공 옆 국소 이완(0.297 Å)과는 별개.
그냥 붙이면 이음매가 생기고, **더 나쁜 것은 n=9 만 이음매가 없어 앵커가 계통적으로 어긋난다**.

## 규약 — 전 n 동일

```
u_target(s, m_n, j) = Σ_{m9 : fold(m9)=m_n}  u_13(s, m9, j) · W(|dz_9|)
W = 1 (|dz| ≤ 6.50 Å) → cos² 테이퍼 → 0 (|dz| ≥ 11.287 Å = 4.5T = 9-셀 대척점)
```
n ≥ 9 는 항이 하나뿐이라 창만 씌운 것과 같고, n < 9 는 셀 주기로 **접는다**(작은 셀의 선형탄성 응답).
검증: 최대|u| 0.2970 Å 전 n 동일(n3 만 접힘으로 0.2732), 창 바깥 정확히 0, 최단결합 1.4109 Å, 배위2 B 3개.
씨앗 사본은 `seeds/` 에 보관 — 재시작 `cp CONTCAR POSCAR` 로 출발 기하가 사라지는 것 방지.

## ★ 창값은 이완이 되찾는다

창이 깎은 변위 RMS 0.0241 Å (원 0.0919). 그런데 **씨앗에서 다시 이완한 n9 의 ΔH_f(JCC) 4.1290 이
13 원본 기하 값 4.1291 과 0.2 meV** → 창으로 버린 것을 이완이 정확히 되찾았다.

## ⚠ 앵커에 새 잡이 필요 없다

"13 의 CONTCAR 그대로" 는 **`14-Lperp_scan_BNNT/L25/VN_p1` 이 이미 그 계산**이다:
POSCAR = 13 CONTCAR (x,y 강체 평행이동 0.0205 Å 뿐, 평행이동 뺀 최대차 1.3e-11 Å),
INCAR 차이는 NCORE/NSIM 뿐이고 **그것이 에너지를 안 바꾼다는 것도 실측**(host q0 −0.0003, qp1 +0.0002 meV).
E = −899.854041 eV. `analyze_VN.py` 가 그 파일을 직접 읽는다.

## ⚠ 덮어쓰기 가드 3 겹 (이 세션에서 실제로 물릴 뻔했다)

| 어디 | 무엇 |
|---|---|
| `make_cells_VN.py` | OUTCAR 있으면 **POSCAR 안 건드림** (`--force` 로만). 재시작 `cp CONTCAR POSCAR` 를 되돌리면 안 되므로 |
