2026-08-24. 연구실 선배의 두 셀(`CONTCAR0_100_p1x2_AA_unrecon`, `CONTCAR0_111_2x2_AA`)을
04-Facet_IP-EA 트리 규약으로 옮겨 만든 아세테이트 모델 2종.

## 선배 셀의 구성 (분석 결과)

두 파일 모두 **종 이름 줄이 없는 VASP4 형식**. 개수 `[.., .., 4, 6, 9, 6]` 에서
결합그래프로 확정한 순서는 **In, As, H(pseudo), C, H, O** (C 는 9개 H 와 1.09 Å).
아세테이트 3개 = C₆H₉O₆ 공통.

| | (100) p1×2 unrecon | (111)A 2×2 |
|---|---|---|
| 두께 | 10 ML | 4 BL |
| 표면 In | 2 | 4 |
| 아세테이트 | 3 → **1.5 ML** | 3 → **0.75 ML** |
| 배위 | In9 에 κ² 킬레이트, In10 에 κ² 킬레이트, **In9–In10 브리지 μ-1,2** 1개 | 브리지 2개(In13–In15, In13–In16) + In14 킬레이트 1개 |
| In–O | 2.15 ~ 2.83 Å | 2.21 ~ 2.57 Å |

★ **1.5 ML 은 비재구성 (100) 의 electron-counting 피복률**이다
([[inas100_ligand_site_vs_electron]] 의 "비다이머 분지"). 재구성 다이머 분지는 1개/다이머라
`C2_100_AA` 와 정확히 대비된다 — 같은 리간드, 다른 표면 재구성.
(111) 의 0.75 ML 은 Cl 규칙과 동일 ([[inas111_cl_ma_p4x3_tree]]).

⚠ 선배 셀의 고정 규약은 **아래 4 원자면**(=2 BL)이다. 우리 트리는 (100) 2면 / (111) 1 BL 이라
**우리 규약으로 통일**했다 — 비교축이 04 트리 내부에 있기 때문.

## ★ 이식 방법: 분수좌표 + 정수 격자대응. **자유회전 금지**

`scratchpad/newcells/{vio.py, build_AA.py, final.py}`.

1. 분수좌표로 옮기므로 선배 a₀=6.1924 → 내 PBE-d **6.189842** 로 자동 스케일 (0.04%).
2. 회전은 **정수 격자대응 M** 만 허용. (100) 은 `M=[[0,1],[1,0]]`(축 교환 —
   선배는 p1×2, 내 셀은 2×1), (111) 은 항등.
3. **윗면 In 층 + 아세테이트 층을 함께** 옮긴다 → In–O 가 선배 값 그대로 살아난다.

⚠ **데인 함정 3개** (전부 직접 겪음):
- **자유 Kabsch 회전은 안 된다.** 선배 표면 In 이 16° 이완돼 있어서 2점 Kabsch 가 그걸
  격자 회전으로 착각한다 → 리간드 층이 15° 돌아가 **주기이미지가 깨진다.**
- **분자별 앵커(각자의 In 기준)** 도 안 된다. (111) 처럼 한 In 이 두 분자를 물면
  이완량 차이만큼 서로 밀려 **O–O 가 1.05 Å 로 겹친다.**
- 윗면 In 을 이상자리에 두고 리간드만 강체 이동하면 In–O 가 **1.75 Å** 까지 짧아진다.
  → 위 3번(In 층 동반 이식)이 이 셋을 한 번에 해결한다.

## 만든 셀 (`01-cells/C4_100_AA_unreconstructed/`, `01-cells/C8_111_AA/`)

| 셀 | 원자 | NELECT | 고정 | In–O | 최단원자간 |
|---|---|---|---|---|---|
| C4 08ML (2×1) | 41 | 216 | 8 (2면+H) | 2.15~2.83 | 1.093 (C–H) |
| C4 14ML | 53 | 324 | 8 | 동일 | 1.093 |
| C8 04BL (2×2) | 57 | 360 | 12 (1BL+H) | 2.20~2.57 | 1.095 (C–H) |
| C8 07BL | 81 | 576 | 12 | 동일 | 1.095 |

전부 짝수 NELECT · 진공 25 Å · pseudo-H 는 facet 확정값(As–H 1.5572 / 1.5608) 그대로.
(100) 은 A1(1×1)을 **DB 축인 x 로 doubling** — 선배 셀도 doubling 축 = DB 축이다
(back-bond 이 짧은 축을 향한다). A1 은 8·14 ML 둘 다 back-bond 이 ±y 라 parity 문제 없음.

## 실행

`k` = C4 Γ3×6×1 / C8 Γ3×3×1. **PREC=Normal** ([[inas_prec_normal_validation]]),
20노드, `run_chain.sh` 로 01-relax→02-dipole 한 잡. **얇은 셀만 제출**
(13520=C4 08ML, 13522=C8 04BL); 14ML·07BL 은 트리·POSCAR 만 준비.

⚠ **Fig.2 footing 주의**: 기존 6모델은 PREC=Accurate 다. 트랙 A IP 를 직접 나열하면
C4/C8 만 **−25 meV** 계통 편차를 갖는다(벌크를 맞춰도 상쇄 안 됨). 한 발판으로 맞추려면
02-dipole 을 PREC=A 로 한 번 더 돌리면 된다 — static 1점이라 싸다.
