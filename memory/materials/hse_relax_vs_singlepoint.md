## HSE full relax → single-point 전환의 오차 예산

PBE-d 이완 기하 위에서 HSE06을 돌렸을 때 **이완으로 더 얻는 에너지**:

| | 00 단계(비자성) | 01 단계(스핀) |
|---|---|---|
| 02 Cl-passv (110) | 4.2 ~ 40.7 meV | 0.0 ~ 2.7 meV |
| 04 InCl3-passv (110) | 10.9 ~ 30.6 meV | 0.0 ~ 1.7 meV |
| **(100) p4×4 pure** | **36.3 meV** | — |

원자 이동은 00에서 최대 0.13 Å, 01에서 최대 0.022 Å. **E_f에 남는 건 pure 대비 차이**라 합계 예산 **~40 meV** (02 최대 +36.5, 04 최대 +19.7). 결함 간 E_f 차이 0.5~2 eV, 유한크기 보정 수백 meV, band-filling 0.219 eV에 비하면 작다. 서열·부호 판정 안 바뀜.

⚠**(100)이 (110)보다 3~9배 크다** (pure 36.3 vs 4.2/10.9 meV). In-dimer 재구성 탓. (100)에서 pure-상대 값은 As_In full relax 결과와 빼서 확정할 것.

극단 예: 04 `Cl-As_In`이 **145 이온 스텝을 써서 27.8 meV**를 벌었다.

## 스핀 이완은 0이지만 스핀 안정화는 크다 — 혼동 말 것

`01_Spin` 단계의 **이완**은 0~2.7 meV로 무시 가능. 그러나 **스핀 안정화**(00 기하에서 ISPIN=2를 켜는 순간 얻는 값)는 크다: 02 `V_Cl-Cl_In` **−268 meV**, `Cl-As_In` **−168 meV** (둘 다 mag=1.000).

즉 **자성 안정화는 순수 전자적이고 single-point SCF가 온전히 잡는다.** mag=1.0인 케이스에서도 뒤따르는 격자 이완이 0.3~2.7 meV뿐 → **이 계에는 유의미한 small polaron 이완이 없다.** 따라서 DFE는 `01_Spin-gam-relax`(ISPIN=2 단일점) 단계에서 읽어야 한다. `00`(ISPIN=1)만 쓰면 최대 268 meV를 놓친다.

## 균일 배율변환은 z를 정확히 맞춘다 — PBE-를-HSE셀에서 이완하면 안 됨

PBE 셀 이완 → `redefine_initial_poscars_lattice.py`로 **세 축 균일 축소**(a0 6.189842 → 6.098297, ×0.9852104464). (100) pure에서 그 뒤 HSE 이완이 z를 바꾼 양:

```
In 층간격  2.9652 → 2.9536 Å  (−0.39 %)
As 층간격  3.0463 → 3.0418 Å  (−0.15 %)
슬랩 두께 13.3557 → 13.3807 Å (+0.19 %)
```

반면 **HSE 셀 안에서 PBE를 이완하면** 면내 −1.48% 압축 → Poisson으로 z가 **+1.6%** 팽창 (InAs C11≈83, C12≈45 GPa; ε_zz = −2(C12/C11)ε_xx). 8 ML 13.36 Å 기준 **+0.214 Å 오차 = 균일배율의 9배**이고, HSE가 실제 이완시키는 양(0.13 Å)보다 크다. **없던 계통오차를 새로 넣는 것.**

→ 배율변환 단계는 번거로워도 **빼면 안 된다.** (2026-07-29 사용자 지적으로 내 반대 제안을 철회)

## 운용 결론

- 중성 스크리닝: PBE-d 이완 → 균일 배율 → **HSE single-point (`NSW=0`)**, `01_Spin` 포함
- 하전(CTL): **이완 필수**. E_rel = E(+1,R_q0) − E(+1,R_q+1) = 101~113 meV로 중성보다 크고, CTL을 직접 이동시켜 상쇄되지 않는다. 대상이 소수(4~12)면 PBE 사전이완 없이 **HSE 직접 이완**이 낫다(씨앗 = q0 HSE 기하)
