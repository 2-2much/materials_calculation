2026-09-17~22. MoTe2 MLFF 학습에서 셀·k점을 어떻게 고를 것인가.

## ⚠ Γ-only 단축은 철회 (사용자 지적, 2026-09-17)
> ★ 이건 **이미 실측돼 있던 사실**이다 — [[mote2_gamma_vs_mesh_measured]]:
> 2H는 기하 OK(0.015 Å)·에너지 아웃(115 meV), **1T는 기하도 파탄(0.092 Å)**.
> 아래는 그걸 모르고 다시 유도한 것. **제안 전에 기존 메모리를 먼저 읽을 것.**

hex n×n 에서 n이 3의 배수면 K→Γ 접힘이라 Γ-only가 성립한다(n=6). 여기에 기대어
"hex 6×6 Γ-only로 10배 싸게"를 제안했으나 **틀렸다**:

1. **1T′는 밴드겹침 60 meV 준금속, 1T는 금속.** 단일 k점이면 Fermi면 적분이 무너져
   힘·에너지가 틀린다
2. ★ **더 나쁜 것 — footing.** 2H만 Γ-only, 1T는 메쉬로 학습하면 **두 상의 계통적 k오차가
   다르고, 국소 FF는 그 차이를 흡수할 방법이 없어 가짜 2H–1T′ 에너지차를 학습한다.**
   즉 Γ-only는 "2H 전용 FF를 받아들인다"는 결정과 한 몸
3. 2H에서조차 **정작 필요한 구간에서 가장 약하다** — 결합이 끊기고 Te가 떨어지는 온도에서는
   국소적으로 갭이 닫히고 금속적 상태가 생긴다

→ 같은 k메쉬 기준 이득만 남는다: hex 7×7(147)은 rect 7×4(168) 대비 **1.3배**.
(hex 6×6(108)은 2.6배지만 반경 10.5 Å라 얇다 — [[mote2_distorted_vte_cell_size]])

## ★ MLFF는 국소적이다 → 학습셀 ≠ 탐색셀

descriptor cutoff(`ML_RCUT` 기본 ~8 Å 반경)만 보므로 한 셀에서 학습한 FF는
**같은 물질의 아무 크기 셀에나 적용된다.** 세 질문을 분리할 것:

| 목적 | 필요 조건 | 권장 |
|---|---|---|
| 학습 (Step 1) | 셀 ≥ 2×RCUT (~16 Å). 그 이상은 낭비 | hex 5×5(75) 면 충분 |
| 탐색 (Step 3) | 클수록 좋음, FF라 공짜 | 7×7 이상 |
| 최종 DFT 재이완 | 답이 수렴해야 함 | hex 7×7 이상 |

`L ≥ 2×RCUT` 표: primitive 3.5 ✗ / 3×3 10.5 ✗ / 4×4 14.0 (RCUT 6이면 ✓) / **5×5 17.5 ✓**
→ host 열진동 데이터를 5×5 로 내리면 168 대비 **1/3**. 큰 셀은 **결함이 들어가야만 하는
데이터**에만 쓴다.

## primitive cell 의 진짜 역할 = 온도가 아니라 **변형**

온도 사다리를 primitive로 대체하는 것은 불가:
- **접근 가능한 배치가 Γ점 포논뿐.** 모든 원자가 자기 이미지와 같은 위상으로 움직여
  zone-boundary 포논도, 국소 변형 기울기도 못 만든다. **1500 K까지 올려도 환경 종류가
  안 늘고 진폭만 커진다.** 학습 데이터의 가치는 다양성인데 primitive는 다양성이 ~0
- T_c 측정은 더더욱 불가: 녹는 건 **무질서의 핵생성**이라 핵이 들어갈 셀이 없으면
  **과열(superheat)** 한다. 그리고 순간온도 상대요동 = √(2/3N) → N=3 이면 **47%**,
  N=168 이면 6.3%

★ **그런데 지금 설계(`ISIF=2` 고정셀)는 변형·부피 데이터를 단 한 번도 안 넣는다.**
metastable 재구성이 국소적으로 다른 밀도를 가지면 FF가 거기서 외삽한다.
변형은 Γ점 자유도라 **primitive 에서 완전히 표현되고 사실상 공짜**다.
→ 기존 도구 그대로 쓸 수 있다: [[mote2_2d_lattice_scan]] (c 고정, POSCAR 3·4행만 배율)
a 를 ±5% 훑고 각 격자상수에서 짧은 MD.

## ⚠⚠ 이 "작은 셀로 학습" 안은 ML_AB 동질성 규칙과 충돌한다
[[mote2_mlff_md_plan]] 의 규칙: 하나의 ML_AB 안에서 ENCUT/PREC/ALGO/EDIFF/ISMEAR/SIGMA/
IVDW/LREAL/POTCAR **그리고 k-그리드**가 전부 같아야 하고, **"2x2x1" 이라는 이름이 같아도
셀 크기가 다르면 Δk 가 다르다. 한 번 오염되면 refit 으로도 복구 안 된다.**
→ **host 데이터를 hex 5×5 로 내리는 안은 그대로는 쓸 수 없다.** 쓰려면 Δk 를 맞추고
(작은 셀은 더 촘촘한 메쉬) **원자당 에너지로 실제 일치를 확인한 뒤** 써야 한다.
같은 이유로 primitive 변형 데이터도 별도 ML_AB 로 두거나 Δk 를 맞춰야 한다.
**확인 전까지는 전부 7×4 단일 셀 유지가 안전하다.**

## ⚠ 공통 함정: 셀마다 k수렴 정도가 다르면 에너지 척도가 어긋난다
학습셋의 **모든 셀을 같은 원자당 정확도(≲1 meV/atom)로 k수렴**시키고 **실제로 재 볼 것**
(세 셀에서 pristine 에너지/원자 비교, 30분). 대부분 상쇄되지만(비교 대상 두 구조의
pristine-like 원자가 같은 오차를 받음) 결함 근방 ~20원자 몫 ~40 meV는 남는다.
