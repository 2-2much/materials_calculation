2026-09-17. `CONTCAR_dist_VTe_2nd_q0` (hex 5×5, 74원자) 를 직접 재서 판정.
두 파일의 a0 는 **3.502559 Å 로 동일** → 기하 이식 가능.

## ★ 5×5는 distorted V_Te 에 대해 실패한다

배정 불필요 지표 = **Mo–Mo 최근접 거리의 a0 이탈**:

| 공공에서 거리 | N | ⟨\|d−a0\|⟩ |
|---|---|---|
| 0–2 Å | 1 | 0.217 Å |
| 2–4 | 4 | 0.364 |
| 4–6 | 7 | 0.247 |
| 6–8 | 7 | 0.137 |
| **8–11** | 6 | **0.173** ← 다시 올라감 |

**셀 경계가 8.76 Å**(= 17.51/2)인데 감쇠하던 섭동이 거기서 되올라간다. 공공에서 가장 먼
두 원자(8.70, 8.71 Å = 이미지 사이 정확히 중간)가 오히려 더 뒤틀려 있다(0.271, 0.296 Å).
→ **이웃 이미지의 왜곡장과 만나고 있다.**

부수 관찰:
- **Te 배위 결손 Mo 가 정확히 3개**(6→5) → 공공 자체는 정상적인 단일 V_Te
- **아래 Te층은 거의 무손상**(max|u| = 0.184 Å) → 왜곡은 공공이 있는 위층에 갇혀 있다
- ★ **위 Te층은 25자리 중 23개만 채워져 있다.** Te 원자 하나가 자리를 완전히 떠났고
  변위가 a0/2 = 1.75 Å 를 넘는 원자가 여럿 → **왜곡이 아니라 재구성**.
  이 때문에 "이상격자 대비 변위" 방식은 자리 배정이 깨져서 못 쓴다

## ⚠ 크기스캔 결과와 모순이 아니다
`01-Size_scan` 의 "n5 부터 충분"은 **대칭 V_Te** 를 **전자적 기준**(결함밴드 분산폭
W<30 meV)으로 판정한 것. 여기는 **재구성된 V_Te 의 탄성 섭동**이고 훨씬 멀리 간다.
**다른 결함, 다른 수렴 질문.** 하나가 다른 하나를 보증하지 않는다. → [[mote2_vte_size_scan_results]]

## ★ 셀 비교 — hex 7×7이 rect 7×4를 전 항목에서 이긴다

| 셀 | 원자 | 최소 image | 반경 | C3 | K→Γ |
|---|---|---|---|---|---|
| hex 5×5 | 75 | 17.51 Å | 8.76 | ✓ | ✗ |
| hex 6×6 | 108 | 21.02 | 10.51 | ✓ | **✓** (n이 3배수) |
| **hex 7×7** | **147** | **24.52** | 12.26 | ✓ | ✗ |
| rect 7×4 (현 계획) | 168 | 24.27 | 12.13 | **✗** | ✗ |

**7×4는 크지 않다 — 최소 적정 크기다.** 비용이 문제여도 셀을 줄이면 안 된다.

### C3 파괴는 이 문제에서 장식이 아니다
V_Te 갭 준위는 **C3v 의 e 이중축퇴**이고, 그 갈라짐 자체가 이미지 상호작용 지표다
([[mote2_vte_size_scan_results]]). 직사각 셀은 C3 를 가질 수 **없어서** 세 대칭등가
왜곡 방향이 서로 다른 이미지 변형장을 본다 → **축퇴를 인위로 가르고 방향을 편향시킨다.**
7×4는 24.518/24.266 = 1.010 로 거의 정사각이지만 대칭은 **정확히** 깨져 있다.
그리고 5×5 hex → 7×7 hex 이식은 자명하지만 직사각으로는 기저변환이 필요하다.

## ★ 돌려야 할 결정적 계산
**5×5의 완화된 재구성 구조를 더 큰 셀에 이식해 0 K DFT 재이완.** 결과 셋 다 답이 된다:
1. 패턴 유지 → 5×5는 구조는 맞고 에너지만 틀렸다
2. 국소화·축소 → 5×5의 넓은 왜곡이 이미지 인공물이었다
3. **확대 → 국소 결함이 아니라 확장 재구성**(국소 1T′ nucleus 등)이고, 그러면
   **셀마다 답이 달라진다** → "metastable 구조 하나"라는 질문 설정을 다시 봐야 한다

이건 Step 3 블라인드 탐색의 눈금자도 된다([[feedback_validate_diagnostic_first]]):
손으로 만든 distort_V_Te 가 진짜 극소점이면 블라인드 탐색이 그것을 다시 찾아내야 한다.
