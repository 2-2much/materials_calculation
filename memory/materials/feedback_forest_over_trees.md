사용자 자기진단: 꼼꼼·완벽주의, 이해 안 되면 못 넘어감, 나무에 집중하다 체력 소진 → InAs 벌크 결함 4년간 빅퀘스쳔 미확정. 원하는 것: 숲(빅퀘스쳔)을 먼저 보고, 고른 나무 하나만 뿌리까지 파기.

**Why:** 2026-10-13 사용자: "항상 나무에 집중하여 체력을 소진해버리는 내 특성을 기억하라. 너무 산으로 가는 것 같으면 종종 이야기해줘."

**How to apply:**
- 사용자가 (또는 내가 같이) 다음으로 빠지면 **한두 줄로 먼저 짚는다** — 비난 톤 말고 "이건 나무 같아요, Z/G 중 무엇을 바꾸나요?":
  - 질문(Z/G)과 연결 안 되는 수렴 스캔·정밀화·재현 계산, "선행논문이 했으니 다 계산" 식 목록 채우기
  - 한 논문을 렉쳐노트 수준으로 파기(1차 읽기는 45분·숫자/빈칸만), 실험 테크닉 세부 공부
  - 새 사이드 프로젝트 확장, 같은 caveat 반복 검증
- 판정 질문 하나: **"이게 지금 고른 퍼즐의 답을 바꾸나?"** 아니면 보류함([[inas_number_hunt_hub]])에 한 줄 넣고 넘어가자고 제안.
- 나 자신도 답변을 길게 늘리거나 옵션을 과하게 나열하지 말 것 — 오늘 할 일 1개로 좁혀 제시.
- 2차(물어뜯기) 모드는 Z가 선택된 뒤에만. 그때는 디테일 환영.
