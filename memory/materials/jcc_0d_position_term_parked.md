2026-10-15 MP 1995 렉노 읽다가 나온 논의. **사용자가 삼천포라며 접어 둠 — 먼저 꺼내지 말 것.**

- JCC δE₀는 host 밴드끝으로 정의 → 결함 위치(중심/표면) 무관 (사용자 지적, 맞음).
- 따라서 JCC(∞) = CKT − e²/2C(host)가 모든 결함에서 **구성상** 성립 → "표면 Si_Ga로 CKT−JCC 비교" 제안은 동어반복, 철회. 남는 차이는 (B_결함−B_host)/L³뿐.
- MP가 CKT와 어긋나는 이유 규명은 불필요(CKT가 정답 제공) — 사용자 판단.
- 후보 아이디어: Eq.(7) 숨은 가정 ∫ρ_d U₁ ≈ ∫ρ_band U₁. 2D는 U₁(z)라 자동 성립, 0D는 U₁(r)이라 아님 → 위치항 ~e²/(2ε_in R) ≈ 0.1 eV(고전 추정). 정답지 = 보정 불필요한 q0 셀. 미검증·원문 미확인.
