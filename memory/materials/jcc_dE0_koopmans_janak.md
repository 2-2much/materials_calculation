2026-09-08. Zhang PRB 108, 245305 (2023) Eq.(8) 개념 정리. 계산 없음, 발표용 논리.

## 1. qε_b 는 왜 붙는가 — 새 항이 아니라 정의의 일부
형성에너지 표준정의 `ΔH_f = E(α,q) − E(host) + Σn_iμ_i + q(ε_VBM+E_F)` 의 마지막 항이
**전자 저장고(reservoir) 항**이다. +q로 만들려면 전자 q개를 셀 밖 어딘가로 보내야 하고,
그 "어딘가"의 화학퍼텐셜이 ε_VBM+E_F 이다.

여기에 **α = "VBM"이라는 가짜 결함**(원자는 안 건드리고 VBM에서 전자 하나만 뺀 호스트)을 넣으면
Σn_iμ_i=0, E_F=0 이므로 그대로 Eq.(8)이 나온다:
`δE₀ ≡ −ΔH_f(VBM,+1,3DJM) = E^{N₀} − E^{N₀−1} − ε_VBM`

## 2. 물리적 읽기 — "전자를 어디에 놓았나"가 두 개
| | 종착지 | 값 |
|---|---|---|
| `E^{N₀}−E^{N₀−1}` | 젤리움 (진공 포함 셀 전체 균일) | ΔSCF |
| `ε_VBM` | 진짜 저장고 = 호스트 VBM 상태 | 고윳값 |
**δE₀ = 잘못된 저장고를 쓴 대가.** TRSM은 보상전하를 진짜 VBM에 넣으므로
`ΔH_f(VBM,+1,TRSM) ≡ 0` (아무 일도 안 일어남) → δE₀ = TRSM − 3DJM.

## 3. Janak / Koopmans / PPLB 연결
- **Janak**(엄밀, 범함수 무관): `∂E/∂n_i = ε_i`. 궤도이완 항은 변분 정상성으로 정확히 0.
  (HF Koopmans가 "궤도동결" 가정 때문에 근사인 것과 대조)
- **PPLB 조각선형성**: 정확 범함수에서 E(N)은 정수 사이 **직선**, 정수에서 꺾임.
  Janak과 합치면 "E(N) 직선 ⟺ ε_HOMO가 N에 무관".
- **★Eq.(8)의 ε_b 분기가 곧 미분 불연속성**: q>0은 왼쪽 미분(ε_VBM), q<0은 오른쪽 미분(ε_CBM).
  임의 규약이 아니다.
- **½의 정체 = Slater transition state**: `E^{N₀}−E^{N₀−1} = ∫ε_H dN = ε_H(N₀−½)` (선형 가정)
  → `δE₀ = −½ ∂ε_HOMO/∂N = ε_H(N₀−½) − ε_H(N₀)`. 01단계에서 분수 NELECT로 **2.5% 이내 확인**.

## 4. 따름정리 — 젤리움이 ΔSCF 갭을 부풀린다
E(N)=E_lin+½α(N₀−N)² 로 두면 δE₀=−α/2 이고
`IP = −ε_VBM + α/2`, `EA = −ε_CBM − α/2` → **ΔSCF gap = KS gap + α**.
hBN 6×6/L_z=30 에서 **α = 2|δE₀| = 1.79 eV** 만큼 갭이 가짜로 벌어진다.
⚠ IP·EA 자체는 전혀 대칭이 아니다(6 vs 2 eV). 비대칭은 전부 ε_VBM/ε_CBM이 지고 있고
Eq.(8)이 그걸 빼내므로 **남는 아티팩트만 대칭**해진다 → [[jcc_dE0_charge_symmetry]]

## 5. 곡률의 원인은 XC가 아니라 기하 — 증거 3종
보통 E(N) 볼록성은 LDA/GGA 자기상호작용 이야기지만 여기선 아니다:
| 증거 | 실측 | XC 오차라면 |
|---|---|---|
| L_z 선형성 | δE₀·S vs L_z 기울기 −7.2951 eV·Å (이론 −K=−7.5396, 3.2%), 886 meV 구간 RMS 3.0 meV | 진공두께에 선형일 이유 없음 |
| 1/S | δE₀·S 가 n=6~9에서 1.7% 일정 | 이유 없음 |
| **q² 부호무관** | 도너 +0.03647 vs 억셉터 +0.03684 eV/Å (1%) | SIE는 추가/제거 **비대칭** |
⚠정직하게: δE₀는 측정량이라 잔여 XC 기여도 흡수한다. 논문은 분해할 필요가 없고,
필요한 성질은 "결함 무관 호스트 전용량"뿐 → [[jcc_eq7_defect_independence]]

## 6. 값싼 교차검증 (발표용)
`NELECT = N₀−0.5` 한 잡만 더 → `δE₀ ≈ ε_HOMO(N₀−0.5) − ε_VBM(N₀)`.
전체 ΔSCF의 대체품은 아니지만(선형성 가정, 2.5%), **전혀 다른 두 경로가 같은 숫자**라는 게 가장 센 증거.
