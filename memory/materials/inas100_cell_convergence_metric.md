2026-07-29. `04-inplane_100_As_In-Cl` 셀 선택에서 **잘못된 지표 두 개가 반대 결론을 냈다.**
검증 에이전트가 잡았고 재계산으로 확인했다.

## ✅ 쓸 것 — `E_b = pristine CBM − 결함 밴드 최저점`

같은 셀의 pristine 짝과 비교하고, **In 4d 준내각(밴드 50–150)** 에서 정렬한다.
- **k-집합 무관**: 4 k점(2×2×1)과 18 k점(line-mode)이 **1 meV 이내 일치**
- 최저점 아닌 곳의 밴드 교차에 면역
- 정렬 계통오차 ±20 meV (코어전위 기반 독립 정렬로 교차검증)

## ❌ 쓰지 말 것 1 — k 평균 오프셋 `⟨P⟩ − ⟨D⟩`

서로 250 meV 씩 미수렴한 두 양의 상쇄에 기댄다. 그리고 **한 k에서 밴드 교차가 일어나면
그 값이 결합에너지가 아닌데도 평균에 섞인다.**
실측: p4×3 의 Y 점에서 결함 성격이 462→463 으로 넘어간다(PROCAR w_def 0.039 vs 0.246).
그 오염된 36 meV 가 p4×3 평균을 195 로 끌어내려 **단조성을 파괴 → "수렴한 것처럼" 보이게** 했다.
→ **밴드를 인덱스로 추적할 때는 매 k마다 PROCAR 투영으로 성격을 확인할 것.**

## ❌ 쓰지 말 것 2 — 초과 밴드폭 (결함 폭 − pristine 폭)

0 에서 평탄해지지 않고 **0 을 통과해 계속 내려간다**: +123 → −29 → −41 meV.
p4×5(−41)가 p4×4(−28)보다 0 에서 더 멀어 "p4×4가 p4×5보다 낫다"는 자기모순이 된다.
**−28 ≈ 0 은 평탄역이 아니라 부호 교차점**이고 그게 p4×4 에 걸린 건 우연이다.
(음의 초과폭 자체는 물리다 — 결함 퍼텐셜이 낮은 k를 더 세게 끌어내려 밴드가 압축된다.)

네 셀 모두 **a = 17.51 Å 고정**이다. p4×5 는 "더 큰 셀"이 아니라 **b 병목만 없앤 셀**이고

## ⚠ 직교 셀에만 있는 것 — 구경꾼(clean) 사슬

a=4단위 안에 bare-In 사슬이 **2개**(8.754 Å 간격)다. 직교 셀은 결함이 한 사슬에만
들어가고 **다른 사슬은 손 안 댄 채 남는다** → pristine CB 바닥의 축퇴쌍이 갈라진다:

| | pristine CB 바닥 | 결함 후 |
|---|---|---|
| p4×3 | 463·464 둘 다 0 | 462 **−302**, 463 **+18** |
| p4×4 | 617·618 둘 다 0 | 616 **−202**, 617 **+4** |
| p4×5 | 771·772 둘 다 0 | 770 **−161**, 771 **+1** |
| par4×3 | 463=0, 464=**+181**(축퇴 없음) | 462 −150, 463 **−101**, 464 −134 … **전부 하강** |

PARCHG Voronoi 로 배정 확정(p4×3, `chain_split.py`): 결함사슬 31·46·80 / clean 7·15·23.
**462 는 Γ·X·S 에서 결함사슬 20~23 % vs clean 0.4~0.9 %**, 463 은 반대. Y 에서만 교차
(= k평균 지표를 망친 그 교차의 독립 확인).

⇒ 직교 셀은 **희박 결함의 topology**(교란 상태 + 손 안 댄 host 연속체)를 재현하고,
결함 준위를 **pristine 별도 계산 없이 그림에서 직접** 읽을 수 있다.
전단 `b'=b+a/2` 는 b' 병진이 사슬을 옆 사슬로 옮겨 **모든 사슬이 결함을 갖게** 만들므로
구경꾼이 존재할 수 없고, 밴드 끝 자체가 이미 교란돼 split 이 안 보인다.

⚠ 단, **split 크기 302/202/161 meV 는 거의 전부 유한크기다.** InAs 도너 참값은
a_B=349 Å / 1.4 meV — 예쁘게 갈라지는 그림을 결합의 물리로 읽지 말 것
([[shallow_donor_inas_supercell_limit]]).

## 셀 선택 함의

사슬축 이미지 거리로 세우면 네 셀이 **완전히 단조**다. 전단(b'=b+a/2)이 순수 b 방향 최근접
이미지를 **2b = 26.26 Å** 으로 밀어내므로 **par4×3 은 127원자로 211원자짜리 p4×5 보다 낫다.**
⇒ **물리는 par4×3 을 가리킨다. 결정은 물리가 아니라 slabcc 제약이다.**
⚠ slabcc 가 전단 슬랩셀에 정말 불가한지 재확인할 값어치가 있다. 중성 결함엔 애초에 보정이
불필요하고, 하전 보정만 분리하는 선택지도 있다([[inas100_par4x3_sheared_cell]]).
