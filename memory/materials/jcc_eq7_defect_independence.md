## 항에 이름 붙이기
| 항 | 수식 | 무엇 | 결함 정보 |
|---|---|---|---|
| **A** | `ΔH_f⁰(α,q)` | 진짜(무한셀) 형성에너지 | ✅ **전부** |
| **B** | `γ/L_S` | 결함전하 ↔ 면내 주기이미지 | ✅ 있음 |
| **C** | `q²L_z/(24ε⊥L_S²)` | 젤리움이 진공까지 퍼진 항 | ❌ |
| **D** | `Λ(ρ_{C,V},ε∥)/L_S²` | 평평한 젤리움 vs 호스트 밴드끝 모양 차이 | ❌ (ρ는 **호스트** 밴드끝) |

```
Eq.(4)  ΔH_f(3DJM) = A + B + C
Eq.(6)  ΔH_f(TRSM) = A + B + D
─────────────────────────────── 빼면
Eq.(7)  ΔE          =         D − C
```

## ★상쇄 조건은 "결함 무관"이 아니라 "두 모델에서 같음"
3DJM과 TRSM은 **이온화된 전자를 어디 두느냐만** 다르다. 결함 자체(A)도, 면내 이미지(B)도
보상전하 위치와 무관하므로 두 모델에서 동일 → 뺄 때 사라진다.
⚠ 따라서 **γ가 결함마다 달라도 상관없다**. 실제로 07에서 g=γ/q²가 V_N −3.042 vs C_N −3.605로
17% 달랐지만 D−C에는 영향이 없다.
Fig.3(a)의 좌우 그림에서 **정공(⭕)이 같은 자리**인 것이 A·B가 같다는 그림 표현이고,
다른 것은 **빨간 블록 ↔ 파란 물결선**(젤리움 vs 실제 밴드끝 상태)뿐이다.

## 숨은 가정 — 그리고 그게 깨진 곳
정확한 에너지는 `∫ρ_d(r)U₁(r)dr` 인데, 논문은 **결함전하 ρ_d가 ρ_VBM처럼 z-국재**되어 있다고
가정하여 ρ_d를 우변에서 제거한다. `ΔE(α) ≈ ΔE(VBM)` 근사의 근거가 이것.
→ **우리 hBN 억셉터가 정확히 이 가정을 위반한 사례** ([[jcc_acceptor_vacuum_ghost_state]]):
추가 전자의 61%가 진공에 있으면 z-국재가 아니므로 논리 사슬 자체가 끊긴다.

## 실전 함의
"δE₀는 호스트만 계산하면 되고 모든 결함에 같은 값을 쓴다"의 정당화가 이 상쇄다.
단 **게이트를 통과한 결함에 한해서**다 — 판정자는 밴드끝 대비 준위 깊이 + PROCAR 원자투영.
