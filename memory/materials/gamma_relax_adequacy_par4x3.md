2026-08-10. "지금 셀 크기에서 Γ-only 이완으로 원자구조를 믿어도 되는가"를 실측으로 닫았다.
(111) p2×2에서 구조가 이상했던 경험이 발단. **결론: par4×3에서는 충분하다.**

## ✅ 판정 — 56 meV

`In_As`(Γ에서 189 이온 스텝, 이 세트에서 PES가 제일 험한 셀)로 시험:

| | E0 (eV) | 이온 | \|F\|max | |
|---|---|---|---|---|
| **b** 2×2×1 단일점 @ R_Γ | −445.11044 | 1 | 0.1135 | Γ 이완 기하 |
| **a** 2×2×1 이완 (**seed 출발**) | −444.85637 | 111 | 0.0134 ✓ | ⚠다른 극소점 |
| **c** 2×2×1 이완 (**R_Γ 출발**) | **−445.16636** | 73 | 0.0132 ✓ | |

- **`E(c) − E(b) = −56 meV`, 기하 변화 RMS 0.096 Å / max 0.53 Å** ← Γ 이완이 남겨둔 전부.
  가장 움직인 건 Cl6·In49·In31 = **결함 주변 표면 원자**.
- 셀마다 비슷한 방향이라 `E_def − E_pure`에서 더 상쇄된다.
⇒ **이완은 Γ, 에너지·DOS·밴드는 2×2×1 단일점** (= 현행 워크플로) 이 옳다.

## ★ 시험 설계 함정 — seed 에서 출발하면 안 된다

`a`(seed 출발)는 **수렴했는데도 `c`보다 0.310 eV 높은 다른 극소점**이었다. In49 antisite가
3.2 Å 다른 자리(격자 안에 박힘 vs 표면 위로 나와 Cl 2개에 배위)에 앉았다.
⇒ seed 출발 시험은 **k 효과가 아니라 구조 탐색 운**을 잰다. **반드시 R_Γ 에서 출발시킬 것.**
(중간에 "아직 수렴 못 한 것"으로 오판했다가 `reached required accuracy` 확인으로 정정.)

## ⚠ 부수 발견 — Γ 이완이 오히려 더 좋은 골짜기를 찾았다
`In_As`에서 Γ 이완 기하가 seed-2×2×1 이완 기하보다 0.31 eV 낮다. k 정확도 문제가 아니라
**PES 다중 극소점 문제**이며, 이건 별개 사안이다. Γ 이온 스텝이 많았던 셀
(`In_As` 189 · `Cl_In` 114 · `In_i_sub` 107)은 구조 탐색이 불충분할 수 있으니
필요하면 결함 주변을 흔들어 재이완해 볼 것.

## 왜 4k 잔여력 0.1 eV/Å 이 "부족"의 증거가 아니었나
Γ 이완 기하를 2×2×1로 재면 |F|max ≈ 0.10 eV/Å 이 뜨는데, **전부 z=14.6 Å 내부 As 층 6개에
균일하게** 걸린다(pure 포함 14셀 모두 같은 크기). 슬랩 내부는 벌크라 분산이 커서 Γ 한 점으로는
그 층의 밴드 채움을 못 그리는 것. 표면 상태·결함 준위는 국소화돼 평탄하므로 k에 둔감하다.
분해 실측(pure, 동일 기하):

| | \|F\|max |
|---|---|
| gam, LREAL=A, Γ | 0.0139 |
| std, **LREAL=.FALSE.**, Γ | 0.0250 | ← +11 meV/Å 는 **실공간 투영 오차** |
| std, LREAL=.FALSE., **2×2×1** | 0.1060 | ← 나머지는 **k**  |
| std, LREAL=A, ISMEAR=−5, 2×2×1 | 0.1010 | |

⇒ `B→02` 차이가 rms 0.006 뿐 → **tetrahedron 은 원인이 아니다**(pure 는 갭이 열려 부분점유가
없어 Bloechl 보정이 0). 단 **half-filled 결함**(V_As occ 0.50, V_In 0.57, V_Cl-Cl_As 0.47,
Cl_i-*)의 02 힘에는 ISMEAR=−5 경고가 그대로 유효하다.

⚠ `LREAL=A`가 이완 수렴 판정(EDIFFG=−0.015)과 맞먹는 잡음(11 meV/Å)을 깐다. screening 에는
무방하다는 게 사용자 판단(2026-08-10). 정밀 단계에서는 `LREAL=.FALSE.`.
