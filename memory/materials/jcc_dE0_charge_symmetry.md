## ★δE₀의 정체 = Eq.(7)을 α=VBM에 적용한 것 (⚠내가 한 번 틀린 곳)
논문 Eq.(8) 앞 문단이 명시: `δE₀ = ΔE(VBM,+1) = ΔH_f(VBM,TRSM) − ΔH_f(VBM,3DJM)`. 따라서
`δE₀ = Λ(ρ_{C,V},ε∥)/L_S²  −  q²L_z/(24ε⊥L_S²)  =  D − C`
**δE₀ = −C 가 아니다. Λ(=D)은 δE₀ 안에 들어 있다.** "Eq.(3)에 파동함수가 없으니 δE₀가 대칭"은
C만 보고 D를 빠뜨린 잘못된 축약이었다.

## ★왜 대칭인가 — 비대칭이 D에만 갇힌다
가짜 전하배치 `ρ = ρ_loc(+q) + 균일젤리움(−q)`. 정전기 에너지는 **ρ의 이차형식**
`E = ½∬ρρ'/|r−r'|` 이므로 **ρ→−ρ 에 불변**.
| 항 | q→−q | 이유 |
|---|---|---|
| **C** | 정확히 불변 | 우변에 q²·기하·ε⊥ 뿐, 파동함수 부재 |
| **D** | 변함 | ρ_{C,V} 가 q>0이면 VBM, q<0이면 CBM |
→ `δE₀(−q) − δE₀(+q) = (Λ_CBM − Λ_VBM)/L_S²` **정확히**. C는 완전 상쇄.
Janak 판: E(N)−E_조각선형 = ½α(N₀−N)² 이 **우함수**라는 진술과 같다.

## ★★Table II 안의 자연실험 — D의 지문
**black phosphorene vs black arsenene**: 동형(puckered)·같은 셀(L_z=20, 6×6)·
**\|δE₀\|가 1 meV 이내로 동일**(0.131 vs 0.130) → C도 기하도 사실상 같다.
그런데 비대칭은 16 meV vs 1 meV로 **16배** 갈린다.
→ **비대칭은 기하(C)에서 올 수 없다. ρ_CBM vs ρ_VBM 이라는 화학뿐 = D의 지문.**
⚠"δE₀가 작으면 비대칭이 크다"는 기하적 추세는 **없다**(GeS 140/Δ=0, arsenene 130/Δ=1).

## 무엇이 깨뜨리나
| 요인 | 어디에 | Table II 크기 |
|---|---|---|
| **ρ_VBM ≠ ρ_CBM (면내)** | Eq.(6)의 `Λ(ρ_{C,V},ε∥)/L_S²` | 지배적. 0~24 meV |
| ρ_VBM ≠ ρ_CBM (z 확장) | Eq.(3) 유도의 "z-국재" 가정 위반 | 나노튜브·phosphorene |
| XC 자기상호작용 비대칭 | 어떤 대칭으로도 안 묶임 | 작음 |
| ε⊥ | 호스트 성질이라 ±q 공통 | 0 |
`δE₀(−q) − δE₀(+q) ≈ (Λ_CBM − Λ_VBM)/L_S²` → **Table II를 이 식의 실측표로 읽으면 된다.**
깨지는 곳이 물리적으로 말이 됨: 나노튜브=준1차원, 진공이 2방향에서 둘러싸고 CBM이 관 밖으로 샘.
phosphorene=puckered라 VBM/CBM의 z-프로파일 상이. BN·GeS=π/π²처럼 같은 궤도성격 → 0.

## ★★실전 규칙 — 비대칭은 물리가 아니라 진단 지표
대칭성은 δE₀라는 **모델량**의 성질이지, 내가 **측정한** δE₀가 자동으로 갖는 성질이 아니다.
> `|δE₀(+q) − δE₀(−q)|` ≲ 25 meV → 정상 (Table II 전 범위)
> ≫ 25 meV → **밴드 끝 중 하나가 내가 생각하는 그 상태가 아니다**

우리 hBN이 그 사례: 논문은 ±1 둘 다 −0.943인데 우리 δE₀(−1)은 진공 NFE ghost state가
전자를 먹어 무의미 → [[jcc_acceptor_vacuum_ghost_state]]. **그 비대칭이 곧 버그 신호였다.**

## ★우리가 Λ를 쟀나? — 아니다, **조합**을 쟀다
02 출력이 스스로 그렇게 이름 붙인다: `절편 = +42.4905 eV*Ang -> (Lambda + K q^2 L_eff)`,
`L_eff + Λ/(Kq²) = 5.636 Å` — **방정식 하나에 미지수 둘**.
| 경로 | 잰 것 = Λ + K·L_eff |
|---|---|
| 02 호스트 δE₀ 의 L_z→0 절편 × S (8점, RMS 3.0 meV) | **+42.49 eV·Å²** |
| 08 (SEJM−JCC)·S, V_N (산포 5.7%) | −41.0 |
| 08 (SEJM−JCC)·S, C_N (산포 5.6%) | −44.2 |
3~4% 일치 → Λ의 **결함 무관성**은 확인됨. 1/S 항이라 1/L_S→0에서 소멸 = SEJM·JCC 통일(Fig.4b).
절편이 Λ가 되려면 "L_z→0에서 C가 정확히 0" = ε⊥가 L_z 무관이어야 한다:
| 읽기 | 가정 | 기울기 예측 | 절편 |
|---|---|---|---|
| A | ε⊥ = L_z/(L_z−L_eff) 기하희석만 | −0.03824 | K·L_eff/S (Λ 아님) |
| B | ε⊥ = 1.034 상수 | **−0.03700 ✓실측** | Λ/S |
실측은 B에 맞지만 A를 배제할 근거가 없다 → **미해결 3.24% 기울기 불일치와 같은 뿌리**.

## ⚠⚠n=12 는 이 문제를 못 푼다 (내가 두 문제를 섞어 말했었다)
`δE₀·S = Λ − Kq²L_z/ε⊥` — **우변에 S가 없다.** Λ도 C도 똑같이 1/S라 n을 늘려도 안 갈라진다.
(n=6~9에서 δE₀·S가 1.7% 일정한 건 1/S 형태의 *검증*이지 분리가 아니다.)
게다가 **δE₀ 안에는 γ가 아예 없다**(B항이 상쇄). n=12가 푸는 건 **결함 쪽**
`ΔH_f(3DJM) = A + γ/L_S + C` 의 γ vs L_S⁻² 분리뿐 → [[jcc_fig2_sejm_reproduction]]

## ★Λ_CBM − Λ_VBM 은 우리가 **측정 자체를 못 했다**
δE₀(−1)이 진공 ghost state로 전 L_z 구간 깨짐(게이트 8/8 ✗) → 우리에겐 Λ_VBM 쪽 하나뿐.
**0~24 meV 상한은 우리 측정이 아니라 논문 Table II를 빌려온 것.**

## Λ를 진짜 재려면 — DFPT ε⊥ (값싼 8잡, 발표엔 불필요)
02의 중성 호스트 셀 8개에 `LEPSILON = .TRUE.` (기하 재사용, 새 POSCAR 불필요) →
`Λ(L_z) = δE₀·S + Kq²L_z/ε⊥^DFPT(L_z)` 가 **L_z 무관하게 일정한지가 곧 모형 검증**.
3.24% 기울기 불일치 원인도 동시 판정. ⚠72원자 DFPT는 SCF보다 꽤 비싸다.
논문도 "difficulty in defining ε⊥"이라 스스로 인정한 지점.

⚠측정 δE₀는 ΔSCF라 잔여 XC 비대칭도 포함. 0~24 meV를 전부 Λ 차이로 돌리는 건 논문의 **해석**이고,
위 phosphorene/arsenene 비교가 그 해석을 강하게 지지한다.

## 우리 실측이 더 강한 형태의 검증
Table II는 호스트 밴드끝 대칭. 우리는 04/05에서 **진짜 결함**(V_N⁺ 공공 정공 vs C_N⁻ 치환 전자,
화학적으로 완전히 다른 물체)에서 쟀다: dΔH_f/dL_z = **0.03647 vs 0.03684 eV/Å (1.0%)**,
무매개변수 예측 K/(ε⊥S)=0.03698 대비 −1.4%/−0.4%. → [[jcc_dHf_lz_validation]]
이 대칭 덕에 깨진 δE₀(−1) 대신 +1 가지를 써서 억셉터를 구제했고(σ 1.5 meV),
그 대체의 잔여오차 상한이 Table II의 0~24 meV다.
