## ⚠ 사교 셀 전용 k-path — 좌표 확보됨

기존 `02_band` 는 사교 셀인데 **직교 경로 Y-Γ-X-S** 를 썼다. 사교 격자에서 그 경로의
**중간은 대칭선이 아니라** 반교차 꺾임이 생긴다(실제로 관측됨).

올바른 경로 **Γ-X-H₁-C-H-Y-Γ**, 분수좌표(유리수 정확값):

| 점 | 좌표 |
|---|---|
| Γ | (0, 0, 0) |
| X | (1/2, 0, 0) |
| **H₁** | **(13/18, 13/36, 0) = (0.722222, 0.361111, 0)** |
| C | (1/2, 1/2, 0) |
| **H** | **(5/18, 23/36, 0) = (0.277778, 0.638889, 0)** |
| Y | (0, 1/2, 0) |

η=5/18, ν=13/36 이 **유리수로 떨어지는 이유**는 `b' = (a/2)x̂ + (3a/4)ŷ` 라
`|b'|cos γ/|a| = 1/2` 가 정확히 성립하기 때문. **b/a 와 γ 에만 의존하므로 격자상수
스케일이 달라도 같다.**

⚠ **그 LDA 선례는 이 경로를 BZ/ 에 만들어만 두고 실제 HSE 밴드는 Y-Γ-X-S 로 돌렸다.**

## ❌ 폐기 — "초과 밴드폭 ≈ 0" (2026-07-29 철회)

한때 par4×3 의 초과폭(결함 − pristine) −0.042 를 "결함–결함 결합 소멸"의 근거로 썼다.
**틀렸다.** 네 셀로 채우니 +123 → −29 → −41 → −41 meV 로 **0 을 통과해 계속 내려간다**.
평탄역이 아니라 부호 교차이고, p4×5 가 p4×4 보다 0 에서 더 멀어 자기모순이 된다.
근거로 인용하지 말 것. 대체 지표와 실측표는 [[inas100_cell_convergence_metric]].

## 셀 선택 저울 — 판정 (2026-07-29)

지표는 **E_b = pristine CBM − 결함 밴드 최저점** (4k/18k 1 meV 일치).

| | 원자 | HSE 비용 | slabcc | 사슬축 image | **E_b** | 잔여 오차 |
|---|---|---|---|---|---|---|
| p4×3 직교 | 127 | 1.0× | ✓ | 13.13 Å | 302 | +178~222 |
| **p4×4 직교** | 169 | 2.4× | ✓ | 17.51 Å | 202 | **+78~122** |
| p4×5 직교 | 211 | 4.6× | ✓ | 21.88 Å | 161 | +37~81 |
| **par4×3** | **127** | **1.0×** | **✗** | **26.26 Å** | **150** | **+26~70** |

⇒ **어느 셀도 수렴 안 했다.** "p4×4 면 충분"은 성립하지 않는다 — 잔여 80~120 meV.
전단이 최근접 이미지를 2b = 26.26 Å 로 밀어내 **par4×3(127)이 p4×5(211)보다 잘 수렴**한다.
⚠ 네 셀 모두 **a = 17.51 Å 고정** — a 방향 오차는 한 번도 안 쟀다. 직교 고집 시 다음은 **p5×4**.
⚠ par4×3_pure 의 CBM 은 k≈(0.4,0,0)에 있는데 사교 경로가 그걸 비껴가 **20 meV 과소** —
par4×3 실제값은 ~170 으로 봐야 한다(순위는 안 바뀜).

⚠ **slabcc 는 하전 결함에만 필요하다.** 밴드·자성·중성 이완·HSE relax 는 전부 무관.
갈리는 건 하전 상태 형성에너지/CTL 단계뿐이고, CTL 은 같은 셀에서 E(q)−E(0) 을 빼야 해서
두 셀을 섞을 수 없다는 게 진짜 제약이다.
