2026-08-24, `C7_111_ClMA_04BL` 의 `02-dipole` 을 `PREC` 만 바꿔 대조
(`__PREC=N_02-dip__`, INCAR 차이 **한 줄**, 둘 다 160코어/20노드).

## PREC 은 기저를 안 바꾸고 **FFT 격자만** 바꾼다

`ENCUT` 을 명시했으므로 **평면파 수가 51157 로 완전히 동일**하다.
바뀌는 것은 FFT 격자: NGX 60→48, NGXF 120→96 (격자점 0.48배).

| | PREC=Accurate | PREC=Normal |
|---|---|---|
| 평면파 | 51157 | 51157 (동일) |
| NGX / NGXF | 60 / 120 | 48 / 96 |
| LOOP 평균 | 13.15 s | **7.67 s** |
| **가속** | — | **1.71×** |

HSE 는 exchange 적분이 FFT 에 더 무겁게 걸리므로 이득이 이보다 클 여지가 있다.

## ★ 물리는 불변, 정렬 절차만 흔들린다

- **트랙 B**(`IP = V_vac − E_VBM`, 슬랩 고유값 직독): **5.7155 → 5.7156, 0.1 meV**
  → PREC=N 이 전자구조를 바꾸지 않는다는 직접 증거.
- **트랙 A**(macroscopic average): IP **−24.84 meV**, EA 동일하게 −24.84.
  분해하면 `V_vac` +0.76 meV(사실상 불변), **`V̄_slab` +25.61 meV** 가 전부.
  두 면 진공 단차도 +0.02 meV 로 완벽 재현.

## ⚠ 벌크를 PREC=N 으로 맞춰도 **상쇄되지 않는다** (내 가설이 틀렸다)

footing 불일치를 의심해 `06-bulk_ref/PBE-d_PRECN` 을 따로 돌렸다. 결과:
**`V̄_bulk` 도 `E(Γ15v)` 도 `ΔV_bulk` 도 PREC 에 완전히 둔감**(ΔV_bulk 차이 **+0.02 meV**).

| 슬랩 / 벌크 | IP | 기준 대비 |
|---|---|---|
| A / A | 5.7447 | — |
| N / A | 5.7199 | −24.84 meV |
| **N / N** | **5.7199** | **−24.86 meV** (상쇄 없음) |
| A / N | 5.7447 | −0.02 meV |

**왜 벌크만 둔감한가**: 벌크는 셀 전체를 평균해 FFT 격자 오차가 대칭 상쇄된다
(VASP 가 G=0 을 0 으로 잡는 것도 이 때문). 슬랩은 **내부 구간만 잘라** 평균하므로 상쇄가 안 된다.

## 25 meV 의 정체 = 거시평균 잔물결

같이 나빠진 지표: **중앙 평탄부 σ 11.6 → 33.9 meV (3배)**. 거친 격자가 거시평균에 남긴
잔물결이 창 안 평균을 흔든 것이고, **σ 열화와 IP 이동이 같은 크기**다.

## 결론 / 처방

- **HSE 1shot 은 PREC=Normal 로 가도 된다.** 1.71배 가속, 물리 불변.
- ⚠ 단 **"전 셀 통일하면 상쇄된다" 는 근거 없음.** 25 meV 는 계통 불확실도로 **명시**할 것.
  리간드 간 차이 2.03 eV 대비 1.2% 라 서열은 안 흔들린다.
- ⚠ **σ 게이트를 PREC 별로 재보정**할 것. 10 meV 기준을 PREC=N 에 그대로 쓰면 전 셀이 경고로 뜬다
  (40 meV 정도).

## 부수 확인 — 트랙 B 를 주력으로 못 쓰는 이유

리간드 6종 중 **(100) 3종만** 분수점유 0 이라 `E_VBM` 이 정의된다.
(110) Cl·InCl₃ 의 12L, (111) Cl/MA 의 4BL·7BL 은 **밴드가 E_F 를 걸쳐** VBM 이 없다
(얇은 6L 은 되는데 12L 에서 닫힌다 — 양자구속이 풀리며 PBE 반금속성이 드러남).
→ 트랙 B 는 물리를 보증하고, 트랙 A 는 그걸 전 셀에 적용 가능한 형태로 옮긴다.
