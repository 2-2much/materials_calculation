## HSE 원조 3편 원문 확인 (2026-10-01, PDF는 ~/papers/hybrid_functional_defect/)
- HSE 2003 (JCP 118,8207): (a, ω) 2D 최적화를 분자 G2-1 + 일부 고체에서 함 → 극소가 매우 넓어 a=1/4 유지. 반도체 갭엔 ω≤0.15 필요, ω=0.15 는 **정확도·속도 절충**(작을수록 비쌈).
- Erratum (JCP 124,219906): 실제 코드 ω_HF=0.15/√2≈0.106, ω_PBE=0.15·2^(1/3)≈0.189 bohr⁻¹. **지금까지 발표된 모든 HSE 계산에 적용**(→ Heyd 2005 포함).
- Krukau 2006 (JCP 125,224106): HSE06 = ω_HF=ω_PBE=0.11 bohr⁻¹(=0.208 Å⁻¹; VASP 0.2 Å⁻¹=0.106 bohr⁻¹). 13개 고체 갭 ME: ω 0.11/0.15/0.20 → −0.12/−0.28/−0.44 eV (≈ −1.9 eV per Å⁻¹); 반도체 격자 ME 0.018/0.021/0.024 Å (ω↑→격자↑, 미미). **갭은 주로 ω_HF 가 결정**(HSE03≈HSE06@0.11) → Heyd 2005 InAs 0.39 는 HSE06 과 사실상 같은 함수의 값. ω<0.11 은 Gaussian 코드에서 수렴 못 시킴. α 는 내내 0.25 고정 — (α,ω) 공동 튜닝 없음.

## 확정 절차 + gKT 시험 규약 (2026-10-01~05 대화 결론)
1. 2원자 primitive, HSE 자기격자(≈6.104)에서 μ∈{0.1,0.2,0.3}×α 스캔 → 갭=목표 등고선. (μ→0 은 수렴·비용 별도 확인, Krukau/JAP2018 모두 작은 ω 수렴 난항)
2. 등고선 위 3~4점에서 **결함셀** 고정구조 E(q) (0.25 간격) → HOMO(N)·ΔSCF·LUMO(N±1) 비교, 기준 |Δ|<0.05 eV. 곡률 c 이면 HOMO−LUMO=2c.
3. 최종 (α,μ) 로 BM 재적합 → 자기격자에서 갭 재확인, 0.05 eV 넘게 벗어나면 1회 반복.
4. (선택) 3번째 판정자 = HSE+SOC Γ근방 Kane 피팅으로 m*(0.024)·E_P(21.5) 재현 → [[inas_kane_kp_application]].
- gKT 는 **pristine 셀로는 무의미**(전하 비편재 → 곡률 ~1/N 로 자동 통과). 빠지는 분수전하가 국소 결함준위에서 나와야 함(두 전하상태 모두 IPR 확인). 하전보정(216셀 ~0.08 eV)이 기준 0.05 보다 커서 ΔE 엔 이미지보정·ε 엔 −2E_corr/q 일관 적용. GKFO 는 InAs(ε0−ε∞≈3)에서 작음.
- 정수점 꺾임(U, 벌크면 갭)은 물리 — 직선 조건은 정수 사이 구간에만.
- 원리 정리는 [[hybrid_gkt_janak_koopmans_principles]].
- HSE03 총에너지(IP/EA 0.23–0.25 eV 이동)는 에너지차 비교에 쓰지 말 것. 갭·격자만 HSE06 과 비교 가능.
- 그림: `~/papers/hybrid_functional_defect/lecture_assets/hse_range_separation.png` (erfc 분할 · μ별 SR 비율 · erratum 이중계산 최대 +6.8% @2.6 Å).

## ENCUT 통일 결정 (2026-10-06)
- 교수님 지적: 슬랩 400 vs 벌크 결함 300 통일성 없음. 사용자 실측: 벌크 결함 300↔400 에서 결함셀 밴드·형성에너지 차이 거의 없음(수치는 표로 정리 필요).
- 결정(권고, 사용자 동의 방향): **(α,μ) 튜닝 후 최종 벌크 결함 계산부터 ENCUT 400 + 슬랩과 같은 PRECFOCK 로 통일.** 300 결과는 SI 수렴시험으로 보존. 이유: 재계산 어차피 필요 → 추가비용 없음 / 후속 슬랩 논문이 벌크 μ·VBM·결함에너지 재사용 / μ 확정세트([[mu_window_hse_aexx27_21]])가 이미 400/Fast.
- ⚠확인할 것: 현 300 eV 벌크 결함 계산에 쓴 μ 가 400/Fast 세트인지(섞였으면 원소당 수 meV 오차), PRECFOCK 값.
- 논문 범위: 1편 = 벌크 결함만, 슬랩은 후속 논문.
