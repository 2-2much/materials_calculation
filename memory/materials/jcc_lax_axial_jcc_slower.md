## ★ 왜 — 수렴을 지배하는 건 기준셀이다

```
ΔH_f(3DJM) = E_D^{+1} − E_H^{0}  + E_N + ε_VBM     ← 중성 host 기준
ΔH_f(JCC)  = E_D^{+1} − E_H^{+1} + E_N             ← 하전 host 기준 (대수 항등식)
```
하전 host 의 정공은 **튜브에 퍼진 선전하**라 자기상호작용이 −11.74/L_ax 로 크다.
결함 정공은 **국재**돼 있어 그 항이 없다 → η_D ≈ 0, η_H = −11.74/L_ax. **크기 3배가 아니라 성격이 다르다.**
검산 `A_JCC = A_3DJM + A_host = 3.54 − 11.74 = −8.20` (차 0 meV·Å).
진공 방향([[jcc_dimension_hierarchy_measured]], 14번)에서는 두 셀의 오차가 같아 상쇄됐다 (414 → **3 meV**).
**JCC 의 이득은 방향 특이적이다.**

## ⚠ 함정

- **1/L 외삽을 믿지 마라.** 형태가 1/L 이 아니므로 작은 셀에 끌려간다.
  1/L 외삽 JCC 4.505 / 3DJM 4.474 vs **직접 추정(가장 큰 셀의 3DJM) 4.62**
- **1/L³ 을 넣으면 RMS 21→8 meV 로 줄지만 `a₃ = 92 eV·Å³` → 함의 d = 8.4 Å**,
  튜브 지름(4.25 Å)의 2배. **다중극이 아니라 곡률을 삼킨 맞춤 파라미터다.**
- 결함 계열 잔차 **21 meV** (host 는 1.7 meV). 정체는 **탄성**(EDIFFG=−0.01 + 무른 모드)과
  **k 접힘**(ε_VBM 이 122 meV 비단조 드리프트, `H3` 엔 들어가고 `HJ` 엔 안 들어감).
  ε_VBM 을 빼도 잔차 20 meV — k 접힘 단독도 아니다.
- 분리하려면 **기하를 얼리고**(탄성 제거) **k 밀도를 n 에 맞춰 고정**(N_k × n = const)해야 한다.
  사용자 판단으로 얼린 계열은 뺐다 → 현재 A_JCC 는 **정전기 + 탄성 합산값**이다.

앵커: n9 JCC **4.1290** vs 14 의 L⊥=25 **4.1291** (0.2 meV). 논문 Table I 4.187 대비 −58 meV.
⚠ 논문 값은 L_ax = 22.575 Å **한 점**이지 외삽값이 아니다 — 축방향으로 수렴 안 된 값이다.
